  1. Freeze one complete saved state, permitted observations, and at least two supported candidate actions.
  2. Commit every forecast and score before opening reference labels.
  3. Execute only the selected action through the Agent Bridge and commit its execution receipt.
  4. Restore an independent branch from the same saved state for each candidate and obtain its later reference outcome.
  5. Compare forecast and decision behavior with matched inputs, compute, failures, and abstentions.
  6. Verify commitments, selected execution, independent branch identity, and replay. Derived views remain read-only.
